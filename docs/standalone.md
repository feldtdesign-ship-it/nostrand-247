# Standalone build

A single 7.7 MB HTML file with three.js, the loader and an uncompressed model all
inlined as base64. Opens on a double-click with no server and no internet.

Use it for emailing or showing on a laptop with no connection. Do not put it on a
public host: the repo version is 17 KB of HTML plus a 498 KB Draco model and
loads in a fraction of the time.

It cannot take the shop photographs without being regenerated, since everything
is inlined.
